### Ход работы:
При решении задачи, мной сначала была разработана следующая функция:

```python
def two_sum(lst: list[int], target: int) -> list:  
    """Функция, которая возвращает индексы двух элементов списка (lst),  
    которые в сумме дают искомое число (target).  
    :param list lst: список элементов для поиска суммы    
    :param int target: искомое значение суммы двух элементов    
    :return: список, состоящий из кортежей по два элемента, в сумме дающих искомое число  
    
    > two_sum([1,2,3,4,5,6,7,8,9],8]    [(0, 6), (1, 5), (2, 4)]    """  
    
    res = []  
    for i in range(0, len(lst)):  
        razn = target - lst[i]    
        if razn in lst[i:]:  
            j = lst.index(razn)  
            if i != j:  
                res.append((i, j))    
    return res  
```
Данная функция хорошо работает и выдаёт нужные значения, но имеет существенный минус - её сложность равняется $O(n^2)$, а для полного решения задачи необходимо разработать функцию со сложностью $O(n)$. 
Для разработки такого алгоритма нужно избавиться от второго "прохода по списку" (в данном случае это `if razn in lst[i:]`). Это можно сделать, заменив поиск "парного элемента" в списке, на нахождение его в словаре, в котором будут храниться значения которые мы уже "прошли". 
Таким образом, получаем следующую функцию:

```python
def two_sum(lst: list[int], target: int) -> list:  
    """Функция, которая возвращает индексы двух элементов списка (lst),  
    которые в сумме дают искомое число (target).  
    :param list lst: список элементов для поиска суммы    
    :param int target: искомое значение суммы двух элементов    
    :return: список, состоящий из кортежей по два элемента, в сумме дающих искомое число  
    
    > two_sum([1,2,3,4,5,6,7,8,9],8]    [(0, 6), (1, 5), (2, 4)]    """  
    
	res = []  
	seen = {}  
	for i in range(0, len(lst)):  
	    razn = target - lst[i]  
	    if razn in seen:  
	        res.append((seen[razn], i))  
	    seen[lst[i]] = i  
	return res
```
В данной функции "проход по списку" будет лишь один, поэтому его сложность составляет $O(n)$, а значит задача решена.
