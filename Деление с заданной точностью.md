### Ход работы:
Первый этап выполнения задачи -  написание функции calculate. Получилась следующая функция:
```python
def calculate(num1: float, num2: float, epsilon: float = 0.0001) -> float:
    """Функция, которая возвращает результат деления с заданной точностью.

    :param float num1: делимое
    :param float num2: делитель
    :param float epsilon: точность
    :return float: результат деления
    :raises ValueError: если num2 равен 0 или если epsilon равна 0

    > calculate(10,2)
    5.0
    > calculate(10,3,0.2)
    3.4
    """
    if num2 == 0.0:
        raise ValueError("Нельзя делить на 0, измените значение num2.")
    if epsilon == 0.0:
        raise ValueError("Нельзя вычислять с точностью 0, измените значение epsilon или оставьте по умолчанию.")

    res = num1 / num2
    res = round(res / epsilon) * epsilon
    
    return res
```
В данной функции особенно примечательна строка `res = round(res / epsilon) * epsilon`. Данная строчка необходима для вычисления деления не просто "с n знаков после запятой" (как ожидается например для epsilon = 0.1 или epsilon = 0.0001), а для вычислений с заданным *шагом* (например при epsilon = 0.5 от 10/3 ожидается результат 3.5). 
Работает это следующим образом: в `res / epsilon` мы "переводим на другой шаг" наши вычисления, беря за целую "единицу" не 1, а, например, 0.5. Потом при помощи `round()` округляем наше вычисление до целых "единиц", и при помощи `* epsilon` возвращаем результат к обычным единицам.

Но, на практике быстро выяснилось, что данный метод в некоторых случаях выдает ошибку, например:

<img width="947" height="216" alt="image" src="https://github.com/user-attachments/assets/b5d2e30e-1625-4aaa-b388-01c3772685b6" />

Которая возникает из-за особенностей вычисления чисел с плавающей точкой. 
От этой ошибки необходимо избавиться, и для этого функция была дополнена следующим фрагментом:
```python
    rounding = len(str(epsilon))-2
    res = round(res,rounding)
```
Здесь мы находим количество знаков после запятой в epsilon (работает это следующим образом: например, при epsilon = 0.2 при переводе в строку длина будет 3, т. к. строка содержит символы '0','.','2'. Поэтому мы отнимаем от длины 2 (во всех случаях это '0' и '.') и вычисляем сколько знаков после запятой в нашем числе) и дополнительно округляем до этого количества.

Но, при выборе epsilon например = 0.00005 возникает интересная ошибка:

<img width="867" height="216" alt="image" src="https://github.com/user-attachments/assets/05e1aaeb-e070-4d34-b7f8-e3e1473cacb1" />

Почему так получается? Всё дело в том, что при передаче очень маленького float python автоматически переделывает его в строку типа '1e-05'. Таким образом мы получаем len = 5, rounding = 3 и соответствующее округление.
Эту ошибку также необходимо исправить.

Для этого фрагмент кода был отредактирован в:
```python
    rounding = len(f"{epsilon:.9f}".rstrip('0'))-2
    res = round(res,rounding)
```
Здесь `f"{epsilon:.9f}"` принудительно превращает epsilon в строку с 9 (т. к. в условиях диапазон: 10**-1 < epsilon < 10**-9) знаками после запятой. А `.rstrip('0')` откидывает все лишние нули.

Следующий этап - написание функции load_params и соответствующего файла settings.ini.
Получилась следующая функция:
```python
def load_params(file: str = "settings.ini") -> float:
    """Функция, которая возвращает epsilon из файла с настройками.

    :param str file: название/путь до файла
    :return float: epsilon

    > load_params()
    0.0005
    """

    config = configparser.ConfigParser()
    config.read(file)
    return config.getfloat('SETTINGS', 'epsilon', fallback=0.0001)
```
`fallback=0.0001` добавлено на случай, если по каким-то причинам в .ini файле будет отсутствовать epsilon.

import unittest
from delenie import calculate


class TestCalculate(unittest.TestCase):

    def test_null_eps(self):
        """Выдача ошибки при точности равной 0."""
        with self.assertRaises(ValueError):
            calculate(3, 2, 0)

    def test_div_by_zero(self):
        """Выдача ошибки при делении на 0."""
        with self.assertRaises(ValueError):
            calculate(3, 0)

    def tests_div(self):
        """Тесты с различными num1 и num2."""
        self.assertAlmostEqual(calculate(1, 2), 0.5, places=4)
        self.assertAlmostEqual(calculate(1, 1000), 0.001, places=4)

    def tests_eps(self):
        """Тесты с различными epsilon."""
        self.assertAlmostEqual(calculate(10, 3, 0.1), 3.3, places=1)
        self.assertAlmostEqual(calculate(10, 3, 0.5), 3.5, places=1)
        self.assertAlmostEqual(calculate(10, 3, 0.001), 3.333, places=3)


if __name__ == '__main__':
    unittest.main()

```
Формально, т.к. в функции в самом конце calculate() использован round с округлением до конкретного числа знаков после запятой, можно было бы использовать обычный assertEqual. Но для 100% гарантии правильного результата при работе с числами с плавающей точкой лучше использовать assertAlmostEqual.

class TestLoadParams(unittest.TestCase):

    @classmethod
    def setUpClass(cls):
        import configparser
        cls.config = configparser.ConfigParser()
        cls.read_file = cls.config.read('settings.ini')

    def test_file_is_loaded(self):
        """Проверка что файл settings.ini доступен для чтения."""
        # Проверяем, что имя файла есть в списке успешно прочитанных
        self.assertIn('settings.ini', self.read_file)

    def test_range(self):
        """Входит ли epsilon в заданный диапазон."""
        self.epsilon = float(self.config['SETTINGS']['epsilon'])
        self.assertGreaterEqual(self.epsilon, 10 ** (-9))
        self.assertLessEqual(self.epsilon, 10 ** (-1))

    def test_type(self):
        """Тест на формат данных epsilon."""
        self.epsilon = float(self.config['SETTINGS']['epsilon'])
        is_float = False
        try:
            float(self.epsilon)
            is_float = True
        except (ValueError, TypeError):
            is_float = False
        self.assertTrue(is_float)

    @classmethod
    def tearDownClass(cls):
        cls.config = None

```
Интересен тест на доступность файла для чтения, он работает следующим образом:
Метод `config.read` при сохранении в переменную возвращает список с названием прочитанного файла. Если файла нет/его не удалось открыть/он не доступен для чтения, то вернётся пустой список. Поэтому мы проверяем есть ли название нашего файла в списке или он пуст, таким образом выясняя удалось ли прочитать файл.
